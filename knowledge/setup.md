# Настройка

## Как настроить бота у себя

Настройка делается через файл .env в корне проекта: скопируйте .env.example
в .env и заполните значения. После изменения .env перезапустите процесс.

## Переменные окружения

BOT_TOKEN — токен бота от @BotFather в Telegram. OWNER_TELEGRAM_ID — ваш
Telegram ID для уведомлений о заявках (узнать можно у @userinfobot).
BUSINESS_NAME — имя, которое бот показывает в приветствии и дашборде.
DASHBOARD_PORT — порт дашборда мини-сервиса (по умолчанию 3030).

## Вход в админку (безопасность)

Дашборд закрыт входом через Telegram: только владелец (OWNER_TELEGRAM_ID) и
админы, которых он назначил, могут видеть заявки и отвечать клиентам.
ADMIN_TELEGRAM_IDS — дополнительные админы через запятую (владелец входит
всегда). Назначать можно и из дашборда, раздел «Администраторы»: человек
пытается войти, бот присылает вам заявку, вы одобряете — и он входит.
Убрали админа из списка — его сессия умирает мгновенно. DASHBOARD_PASSWORD
(старый Basic Auth) больше не используется.

## Хранилище данных

DATABASE_URL — строка подключения postgres://, включается Postgres или
Supabase вместо JSON-файла. Бесплатный тариф Supabase подходит: схема в
sql/schema.sql применяется автоматически. Без переменной всё хранится в
data/db.json — работает из коробки.

## Подключение LLM

LLM_API_KEY — ключ OpenAI-совместимого API, включает режим умных свободных
ответов. LLM_BASE_URL — адрес API (можно прокси), по умолчанию OpenAI.
LLM_MODEL — модель, по умолчанию gpt-4o-mini. Без ключа я работаю в режиме
правил — это бесплатно и полностью офлайн.
